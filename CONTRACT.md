# Internal module contract

Python 3.11+. Standard library backend; Streamlit/pandas/Plotly UI. All timestamps UTC ISO8601 with timezone. Dicts exchanged across modules. Modes `live` or `demo` must never share DB. Package `newslens`.

Quote: `symbol,price,previous_close,source_time,received_at,feed,market_open,data_mode`. Prices finite positive. Bar: `symbol,time,close` (completed daily bars only).
News: `id,headline,summary,url,symbols,created_at,updated_at,received_at,source,data_mode`. Symbols supplied by provider; AI must not add unsupported symbols. source_text(news) is headline + newline + summary. content_hash covers headline/summary/symbols/updated_at; export helper from news_analysis.
Analysis: `categories` (Finance, Politics & Policy, Macro, Other), `impacts` list of `{symbol,sentiment,evidence,reason}` sentiment positive/negative/neutral/unclear, summary, status (success/error/insufficient), model, prompt_version, analyzed_at, error. Evidence verbatim nonempty substring of source_text. Missing content or source symbols cannot cause individual-stock alerts.
Rule: `id,symbol,direction` (above/below), `threshold,cooldown_seconds,enabled,require_news,categories` (list, news subscriptions). Quote rule checks only price crossing; require_news additionally requires fresh (<24h) evidence-backed corresponding positive/negative news. Baseline seed never triggers on initial observation, stale gaps, new sessions or restart gaps.
Storage class Store(path): init(); latest_quotes()->list[dict]; quote_history(symbol,limit=500)->list; bars(symbol)->list; save_quote(q); save_bars(list); save_news(n)->str hash; news_rows(limit=100)->list (latest version plus analysis/status); pending_news(limit=10)->list; save_analysis(news_id,hash,analysis); rules()->list; upsert_rule(dict)->int; disable_rule(id); delete_rule(id); alerts(limit=100)->list; create_alert(dict)->bool (event_id unique, false if exists); set_delivery(event_id,status,error=''); pending_alerts()->list; put_state(key,value); get_state(key,default=None); log(level,message); logs(limit=50)->list; counts()->dict. Returned JSON fields are decoded. DB saves versions immutable. `alerts`: event_id,rule_id,kind,symbol,created_at,price,reason,news_id,delivery_status,data_mode. Each returned news row contains `analysis` dict or None, `hash` string.
signals.evaluate_rule(rule, previous_quote, quote, news_rows, now, max_age_seconds=180)->dict|None; pure eligibility/crossing only. Worker owns cooldown/state and unique event id. signals.indicators(bars)->dict (`ma20`, `return_5d`, `count`); no incomplete/future bars accepted by callers. signals.news_alert(news, analysis, now, categories, max_age_hours=24)->list[dict] candidates, only linked symbols with non-unclear evidence; ids from worker. Worker stores durable price baseline per rule and sent cooldown state.
config.load_settings(path='config.toml')->Settings with symbols, quote_interval, news_interval, max_age_seconds, feed, db_path, mode; ENV overrides NEWSLENS_MODE, NEWSLENS_DB. Credentials env ALPACA_API_KEY, ALPACA_SECRET_KEY, LLM_API_KEY, LLM_BASE_URL (full base e.g. https://.../v1), LLM_MODEL, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID. No network access/import side effects. UI secrets copied to env only for configured keys; no UI live network or workers. Worker CLI `python -m newslens.worker --once` or daemon; `python -m newslens.demo --reset` synthetic fixtures, `python -m newslens.demo --step` deterministic replay, `python -m newslens.evaluation` report.
provider.AlpacaProvider(api_key,secret,feed='iex'): snapshots(symbols)->list[quote], news(symbols,since)->list[news], daily_bars(symbols)->list[bar]. Uses urllib, finite timeouts, pagination, clean exceptions ProviderError with no secrets. Market clock `/v2/clock` via paper-api.alpaca.markets; do not estimate holidays. Clock failure => market_open false; log or throw. Provider receives only REST. Source time is actual trade timestamp, not fetch time.
news_analysis.Analyzer(api_key,base_url,model): analyze(news)->analysis; no key => error, never heuristic fallback labeled AI. validate_analysis(payload,news)->dict; no external SDK. Explicit JSON prompt and enforce schema via Python checks. Cache in Store/worker.
UI app.py must use above Store APIs, load_settings and lazy imports. Default demo DB data/demo.sqlite; live DB data/live.sqlite. UI sidebar mode selector sets env before load; demo startup initialize fixture only when missing, via demo.seed_demo(store,reset=False). Demo actions demo.advance_demo(store) process deterministic quotes and hand-authored annotated fixtures (NOT real data/NOT actual AI). Demo methods root implements.
